# The Open Earn Smart Farm 🌟

Автоматизированный комплекс для работы с ботом **The Open Earn** (`@TheOpenEarnBot`) и его Mini App (`@TheOpenEarnAppBot` / `https://app.theopenearn.info`).

Разработан специально под пул аккаунтов из проекта **RB_Automatic** с изолированными сессиями, индивидуальными фингерпринтами устройств и ротацией прокси.

---

## 🔍 Результаты реверс-инжиниринга

### 1. Архитектура бота и Mini App
- **Главный бот:** `@TheOpenEarnBot`
  - Реферальная ссылка root-аккаунта (`Xxxcalibur`): `https://t.me/TheOpenEarnBot?start=ref_we4ses4p`
  - **Награды:**
    - Обычный реферал: **0.83 ⭐** (≈ \$0.015)
    - Telegram Premium реферал: **5.56 ⭐** (≈ \$0.100)
    - Пассивный доход: **25.0%** от заработка рефералов
  - **Условие разморозки бонуса:** начисление на баланс происходит после выполнения рефералом заданий.
  - **Онбординг:** Выбор языка (`set_lang_first_ru`) ➔ Подтверждение возраста 18+ (`age_confirm_yes`) ➔ Принятие соглашений (`terms_accept`).
  - **Защита:** Встроенная эмодзи-капча при входе в задания (`Найдите эмодзи: <emoji>`).

### 2. Mini App (`@TheOpenEarnAppBot`)
- Запуск через WebApp (`short_name='run'`) по адресу `https://app.theopenearn.info/api`.
- Авторизация через заголовок `Authorization: tma <initData>`.
- **Ежедневный чекин:** эндпоинт `POST /api/checkin/claim` гарантированно начисляет **+15 TOT** и прокачивает стрик каждого аккаунта.
- **Задания рекламодателей:** подписки на каналы и запуск ботов через `GET /api/tasks/ads` и верификацию `POST /api/tasks/ads/{id}/check`.

## 🛡️ Безопасность и фингерпринты (Никаких "TSSP")

1. **Изоляция сессий:** Оригинальные файлы сессий в `RB_Autimatic` не перезаписываются и не портятся. Проект создает чистые рабочие копии в папке `sessions/`.
2. **Подмена устройств:** Для каждого клиента Telethon передаются индивидуальные аппаратные и программные параметры из `RB_Autimatic/accounts_db.json`:
   - `device_model` (настоящие ПК: Acer Predator Helios, Mac Pro, Custom Rig и др.)
   - `system_version` (Windows 11 x64, Pro)
   - `app_version` (официальные релизы 4.16.8 / 5.4.0)
   - `system_lang_code` и `lang_code`
   - Индивидуальные браузерные `User-Agent`
   - Благодаря этому в Telegram Desktop устройства отображаются как легитимные клиенты, полностью исключая метки `TSSP` или `Telethon`.
3. **Прокси и авто-ротация:** 
   - Автоматическая проверка сокетов перед каждым подключением.
   - Синхронизация с базой битых прокси `RB_Autimatic/dead_proxies.json`.
   - В случае таймаута аккаунт мгновенно переключается на рабочий резервный прокси без остановки сессии.

## 🌳 Режимы реферальной системы

В `config.json` можно переключать параметр `"referral_mode"`:
1. **`"direct"` (по умолчанию):** Все аккаунты регистрируются строго по реф-коду `ref_we4ses4p` (аккаунт Xxxcalibur). Все реферальные звезды и процент стекаются на один главный аккаунт для быстрого вывода.
2. **`"pyramid"`:** Пирамидальное распределение. Главный аккаунт набирает целевое количество (по умолчанию 5), после чего новые аккаунты распределяются по цепочке под реферальные коды предыдущих зарегистрированных участников пула.

## 🚀 Быстрый запуск

Запустите файл **`start.bat`** или выполните в консоли:
```powershell
python main.py
```

### Меню программы:
1. **🚀 Запуск авто-фарма** — прогон пачками (по 5 аккаунтов) со случайными задержками (12–25 сек) и антифрод-паузой между пачками.
2. **🧪 Тестовый прогон одного аккаунта** — ручной выбор и детальный отчет в формате JSON.
3. **📊 Таблица статусов всех аккаунтов** — удобный просмотр балансов (⭐ и TOT), выполненных чекинов и назначенных реферальных кодов.
4. **⚙️ Сменить режим рефералов** — переключение в 1 клик между `Direct` и `Pyramid`.
5. **🔄 Принудительная синхронизация сессий** — перепроверка новых аккаунтов из `RB_Autimatic`.
